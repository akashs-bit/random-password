# React + Vite

## 🔐 Random Password Generator

This is a simple and powerful random password generator built using React and Vite. It helps users generate secure passwords with custom options.

### ✨ Features

- ✅ Generate strong random passwords instantly
- 🔢 Include numbers (e.g., 0–9)
- 🔣 Include symbols (e.g., ! @ # $ % ^ & *)
- 🔡 Include lowercase letters (a–z)
- 🔠 Include uppercase letters (A–Z)
- 📏 Set desired password length
- 📋 Copy password to clipboard with a single click
- ⚡ Instant preview and generation using React
